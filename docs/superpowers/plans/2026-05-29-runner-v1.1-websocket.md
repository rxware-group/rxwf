# Runner v1.1（WebSocket + rxwf-runner）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 按任务逐步执行。步骤使用 `- [ ]` 勾选跟踪。

**Goal:** 交付 v1.1 远程 Runner：WebSocket 任务通道、`rxwf-runner` 生产 Agent、`runner-sdk` 扩展契约；远程节点 MVP 仅 `code` + `executeCommand`；三层 Runner 策略（节点 > 工作流 > 全局 Embedded）；API **单实例**。

**状态：** ✅ **已完成**（2026-05-29 实现；2026-05-30 验收 E2E + nightly CI + 计划 checkbox 同步）。全仓 `pnpm lint:deps` 仍有既有循环依赖（非 Runner 范围）。

**Architecture:** 新增 `runner-protocol` / `runner-sdk` / `runner-agent` 三包；`apps/api` 装配 `InMemoryRunnerGateway` + Fastify WebSocket；`NodeRunnerFacade` 远程分支经 WS 派发；`RunnerDispatcher` 完整调度；Lite SQLite 扩展 `runner_registration_tokens`；凭证桥接与多副本 Redis 路由 **不在本计划**。

**Tech Stack:** Node.js ≥20、TypeScript、Fastify 5、`@fastify/websocket`、`ws`、Vitest、pnpm workspace、Drizzle SQLite。

**设计依据:** [2026-05-29-runner-v1.1-websocket-design.md](../specs/2026-05-29-runner-v1.1-websocket-design.md)

**建议:** 在独立 git worktree 中实施（见 superpowers:using-git-worktrees）。
