# i18n 管理（Admin）

在 **设置 → i18n (Admin)**（`/settings/admin/i18n`）中为指定 Locale **覆盖 UI 文案**。**仅 Admin** 可访问。

## 配置

| 字段 | 说明 |
|------|------|
| **Locale** | 目标语言代码，如 `zh-CN`、`en-US` |
| **Messages JSON** | 键值对对象，键为 i18n 键名，值为显示文案 |

示例：

```json
{
  "nav.workflows": "工作流",
  "common.save": "保存"
}
```

点击 **保存** 后，使用该 Locale 的用户将看到覆盖后的文案。

## 与个人信息语言设置的关系

用户在 [个人资料](/help/settings/profile) 选择的界面语言决定加载哪套 Bundle；本页的覆盖在对应 Locale 上叠加于默认 catalog。

## 注意事项

- JSON 必须合法，否则保存失败。
- 键名需与 `@rxwf/i18n-catalog` 中已有键一致；未知键可能被忽略。
- 建议在测试环境验证后再应用到生产。

## 权限

仅 **Admin** 可访问本页。
