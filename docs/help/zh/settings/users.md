# 用户管理

在 **设置 → 用户**（`/settings/users`）中管理平台用户账号。**仅 Admin** 可访问。

## 用户列表

列表展示每位用户的邮箱、昵称、角色、状态、加入方式与最近活动时间。支持搜索与分页。

| 状态 | 含义 |
|------|------|
| active | 可正常登录 |
| disabled | 已禁用，无法登录 |
| pending | 待激活（如邀请尚未接受） |

## 创建用户

1. 填写邮箱、初始密码与角色。
2. 提交后用户可立即登录（direct 方式）。

## 邀请用户

通过邀请链接或邮件邀请新用户；受邀用户首次登录时完成激活，状态由 pending 变为 active。

## 编辑与禁用

- 可修改昵称、角色。
- **禁用** 用户后保留数据但阻止登录；可重新启用。
- **删除** 为不可逆操作，执行前会二次确认。

## 重置密码

Admin 可为任意用户生成随机临时密码，或通过邮件发送重置链接（需已在 [系统设置](/help/settings/system) 配置 SMTP）。
