# 凭证

在 **设置 → 凭证**（`/settings/credentials`）中集中管理 API 密钥、OAuth 等结构化凭据，供节点与集成引用。

## 创建凭证

1. 选择 **凭证类型**（如 API Key、Basic Auth 等，取决于平台已注册类型）。
2. 填写显示名称与各类型要求的字段（密钥字段在保存后掩码显示）。
3. 保存后出现在凭证列表。

## 在工作流中使用

- **HTTP Request**、**Tool (HTTP)** 等节点可在参数中选择已保存凭证，避免明文写入节点配置。
- [Web Search](/help/settings/web-search) 可关联 `apiKey` 类型凭证。
- [模型目录](/help/settings/models) 的 OpenAI 兼容 Provider 可引用 API Key 凭证。

## 删除

删除凭证前确认无活跃工作流依赖；删除后引用该凭证的节点执行将失败。

## 与环境变量

| 凭证 | 环境变量 |
|------|----------|
| 结构化、多字段、可轮换 | 简单键值、`$env` 引用 |
| 节点下拉选择 | 表达式 `$env.KEY` |

敏感信息优先使用凭证类型，便于审计与轮换。

## 权限

所有登录用户通常可创建与管理自己的凭证；具体以 RBAC 与部署策略为准。
