# 工作流变量

在 **设置 → 变量**（`/settings/variables`）中配置 **全局工作流变量**，供所有工作流在表达式中通过 `$vars` 引用。

## 添加变量

1. 填写 **键名**（Key）与 **值**（Value）。
2. 可选勾选 **敏感**：列表与日志中掩码显示，编辑时需重新输入。
3. 选择 **测试 / 生产** 启用范围（可仅测试、仅生产或两者皆启用）。
4. 保存单行或批量维护列表。

## 在表达式中使用

```javascript
{{ $vars.MY_API_KEY }}
{{ $vars.BASE_URL + '/v1/items' }}
```

详见 [表达式与模板](/help/expressions) 中 `$vars` 说明。

## 测试与生产

| 开关 | 说明 |
|------|------|
| 测试启用 | 测试模式执行时可读取 |
| 生产启用 | 生产模式执行时可读取 |

同一键名在测试与生产可配置不同值（通过 testId / prodId 区分实例）。

## 与环境变量的区别

| | 变量 (`$vars`) | 环境变量 (`$env`) |
|--|----------------|-------------------|
| 设置页 | [变量](/help/settings/variables) | [环境变量](/help/settings/env) |
| 键名 | 用户自定义 | 固定 `RXWF_*` 白名单 |
| 测试 / 生产 | 可分环境不同值 | 全平台单套运行时值 |
| 典型用途 | 业务配置、API 端点、Feature Flag | 公网 URL、SMTP、品牌、LangSmith 等平台参数 |

## 权限

所有登录用户均可查看与编辑全局变量（按部署策略可能限制；生产环境建议仅 Admin 修改敏感项）。
