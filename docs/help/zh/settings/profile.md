# 个人资料

在 **设置 → 我的**（`/settings/profile`）中管理当前登录用户的个人信息、安全选项与界面偏好。

点击设置窗口标题栏 **帮助** 按钮（? 图标）可打开本页说明。

## 个人资料

| 字段 | 说明 |
|------|------|
| 头像 | 上传本地图片（最大 256 KB），或移除恢复默认字母头像 |
| 昵称 | 显示名称，最多 64 字符；留空时使用邮箱前缀 |
| 邮箱 | 只读，登录账号标识 |

修改后点击 **保存** 生效。

## 安全

- **修改密码**：跳转至独立密码修改页（`/change-password`）。
- **退出登录**：清除当前会话。

## 角色说明

页面底部提供 **角色与权限** 链接，跳转至 [角色与权限](/help/settings/roles) 查看 RBAC 说明。

## 外观

| 选项 | 说明 |
|------|------|
| 界面语言 | 切换 UI 语言（如中文 / English），立即生效并写入浏览器本地存储 |
| 主题 | 深色 / 浅色，仅影响当前浏览器 |

管理员用户的邮箱旁会显示 **Admin** 标签。

## 权限

所有登录用户均可编辑自己的资料与外观；无法在此页修改其他用户或系统配置。
