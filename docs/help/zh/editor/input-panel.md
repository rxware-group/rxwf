# INPUT 面板

节点属性弹窗左侧的 **输入** 面板用于查看上游数据与环境上下文。

## 显示方式

输入数据以 **JSON** 格式展示（只读 JSON 编辑器，支持语法高亮与折叠）。多 item 时显示为 JSON 数组。

## 搜索

标题行右侧点击 **放大镜** 展开搜索框，在 JSON 文本中**高亮**匹配内容（不区分大小写）。清空搜索后输入框自动收起。

## 数据来源

- **前序节点**：标题栏搜索按钮右侧的下拉框，选择已连接的上游节点输出。
- **Variables and context**：`$now`、`$today`、`$execution`、`$workflow`、`$env`、`$vars` 等（以上游执行或测试设置填充）。

若上游节点尚未执行，可点击 **执行 {节点名}** 获取预览数据。

## OUTPUT 面板

OUTPUT 面板同样以 JSON 编辑器展示当前节点输出（HTTP 节点等特殊类型除外）。
