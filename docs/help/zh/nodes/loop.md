# Loop 节点

## 用途

按上游输入的 **Items** 逐批迭代执行 **循环体**，全部轮次完成后，将汇总结果从 **done** 出口输出。Loop 为 **逻辑** 节点，适合对每条或每批数据重复执行一段子流程（Set、Code、HTTP 等），并自动合并各轮出口输出。新工作流优先使用 Loop；legacy **Split In Batches** 见 [splitInBatches](/help/nodes/splitInBatches)。

## 出口

| 出口 | ID | 说明 |
|------|-----|------|
| **loop** | `0` | 连接循环体；每轮向循环体注入当前批次 Items |
| **done** | `1` | 全部批次完成后输出；内容为各轮循环体 **出口节点** 输出的合并 Items |

画布上 **done** 在上、**loop** 在下（与 ID 无关）。

```
上游 → Loop ──loop(0)──→ [循环体 A → B → …]
         │                      │
         └──done(1)──→ merge / set …
```

## 参数

| 参数 | 说明 |
|------|------|
| **每批 Items 数**（`batchSize`） | 每轮处理的 Item 数量，默认 `1`；如输入 5 条、`batchSize=2` 时执行 3 轮（2+2+1） |

## 执行行为

1. 收到上游 Items 后按 `batchSize` 切批。
2. 对每批按拓扑执行 **loop** 出口所连循环体；循环体入口收到的是**该批次** Items，而非完整上游数组。
3. 每轮结束后收集循环体 **出口节点**（连向循环体外的节点）输出，追加到 done 汇总。
4. 全部批次完成后 **done**（`1`）向下游传递汇总 Items；**loop**（`0`）不产生持久输出。
5. 上游 **无 Items** 时跳过循环体与 done，不产生输出。

循环体末端 **可以** 回连 Loop 的 **main** 输入（合法回环）；**不允许** 循环体内部与 Loop 无关的环，或 done 分支连回 Loop。

## 常见错误

| 错误码 / 现象 | 说明 |
|---------------|------|
| **E2002** | 未连接 **loop** 出口（`0`），缺少循环体 |
| **W1020** | 未连接 **done** 出口（`1`）；迭代结果无法向下游传递 |
| 保存失败「contains a cycle」 | 检查是否在 loop 分支外形成非法环 |
| Partial 调试无汇总 | 选中 Loop 时 OUTPUT 展示 done 汇总；循环体按 `(1/3)` 轮次展开 |

## 示例

### 示例 A

`batchSize=1`：对 100 条订单逐条调用 HTTP 更新状态，done 出口合并全部响应 Items。

### 示例 B

`batchSize=5`：批量写入数据库前，循环体内 Set 节点整理字段，done 接 Merge 与下游报表。

### 示例 C

循环体含 IF：每批 Item 按 `$json.skip` 过滤，done 汇总仅含实际处理过的轮次输出；日志左侧显示 `节点名 (2/5)` 便于逐轮排查。
